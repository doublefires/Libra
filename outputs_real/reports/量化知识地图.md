# Libra 用到的量化知识地图（教学版）

> 一句话：这套系统不是"选股模型"，而是**宏观择时 + 仓位管理 + 交易执行**系统。
> 管线：`数据(PIT) → 特征(z-score) → 打分(加权+tanh) → 仓位(分档+平滑+步幅) → 执行(T+1账本+盘中规则) → 评估(回撤/Calmar)`

---

## 第一层 · 数据基础设施

### 1. Point-in-Time（PIT）/ as-of 视图 ★最核心
- **定义**：任何时刻 t 的计算，只能使用"在 t 之前已经发布"的数据。
- **代码**：`barometer/timeline/point_in_time.py` 的 `available_at() / latest_known() / as_of_points()`；它是全库唯一的取数闸门。
- **实现**：`release_dt <= as_of` 才可见；**release 缺失的行永远不可见**（宁缺毋滥）。
- **为什么**：这是最容易毁掉回测的东西 —— 未来函数（look-ahead bias）。
- **坑**：拿"数据日期"当"发布时点"过滤。例：8 月 CPI 数据日是 8/1，发布日却是 9/10 20:30。

### 2. 数据时点 vs 发布时点（publication lag）
- **代码**：`rawdata/schema.py` 的 `REQUIRED_COLUMNS`；日报 `daily.input_snapshot()`。
- **实践**：日报把"数据日 + 精确到分的可用时点 + 值"全列出来，这是很专业的可审计设计。

### 3. 数据修订 / Vintage（real-time vs final）
- **定义**：宏观数据 first → revised → final。回测只能用当时的 first 值。
- **代码**：`barometer/rawdata/revisions.py`（`REV_RANK`、`as_of_series`、`diff_revisions`）。
- **为什么**：美国 GDP/CPI 修订幅度常很大，用 final 值回测 = 开天眼。

### 4. 复权（Adjusted Price）
- **代码**：`etf_corr_scan.py` 的 `adjust="qfq"`（前复权）。
- **坑**：前复权价会随新分红**重写历史**，跨时点做 PIT 会不一致；严谨做法用后复权或复权因子。

### 5. 交易日历 vs 自然日
- **代码**：`barometer/timeline/trading_calendar.py`，`pd.tseries.offsets.BDay`。
- **坑**：用自然日算 20 日均线必错；用 BDay 会漏掉中国节假日。

### 6. 稳健统计：MAD 异常值检测
- **代码**：`rawdata/clean.py`：`|x - median| > 8·MAD` 打 `outlier` 标。
- **为什么**：均值/标准差对异常值极敏感，中位数 + MAD 是稳健统计标配。

### 7. 数据工程：幂等 / 增量 / 去重
- **代码**：`RawStore.upsert_recent`、`_realtime_merge`、`append_log` 的 `drop_duplicates('t')`。

## 第二层 · 特征工程

### 8. 收益率：简单收益 vs 对数收益
- `returns.py` 用简单收益 `p1/p0 - 1`。简单收益可加权（组合直观），对数收益可加（时间可加）。

### 9. 滚动窗口统计
- **代码**：`indicators/transforms.py` 的 `sma` / `rolling_std`。
- **核心**：窗口只向过去取，t 时刻只含 t-19..t。

### 10. 滚动 z-score（标准化）★
- **代码**：`scoring/v9.build_features`：`z20=(v-mean20)/std20`；`z1=(v_t-v_{t-1})/std20`。
- **为什么**：把量纲完全不同的指标搬到同一把尺子上。
- **坑**：**用全样本 mean/std 就是未来函数**，必须滚动。`transforms.zscore()` 明确注明"仅展示/调试"。

### 11. tanh 压缩 ★
- **公式**：`Score = 100·tanh(2·Σ wᵢzᵢ)`。
- **为什么**：把无界线性组合压到 [-100,+100]，抑制极端值。
- **副作用（很重要）**：**饱和**。|x| 大时 tanh→±1，导数→0，边际敏感度归零。这就是为什么周五 -90 分时"油价只贡献 3.35 分"——被别的特征提前推饱和了。

### 12. 特征冗余 / 共线性
- `V9.TREND_SIGNS` 的 5 个特征**全是** `FLOW_WEIGHTS` 的子集 → 趋势核其实是宏观因子的子集，有效权重被放大。
- **原理**：两个高相关特征各给 0.1，等于给那个因子 0.2。

### 13. 事件型特征（点对点变化率）
- `brent_ret10_z`：布伦特 10 日涨幅再做 20 日 z。油价是"短期异动"，水平值没信息，变化率才有。

### 14. 动量 / 趋势 / 加速度
- **代码**：`transforms.trend_momentum_series`（一阶差分=趋势，二阶差分=加速度）；`v7_position.trend_score`。
- **理论**：时序动量（time-series momentum）是少数跨资产被验证的异象。

### 15. 历史分位数
- `transforms.rolling_pct`（≤ 计数占比，PIT）。比 z-score 更抗肥尾。

### 16. 年化波动率
- `std × sqrt(244)`（A 股一年 ≈244 交易日）。假设收益不相关，通常低估有波动聚集的尾部。

### 17. 过热合成指标
- `heat_metrics`：zr20/zr5/zdist/zvol 加权 → tanh → [0,1]。

## 第三层 · 信号合成与因子评价

### 18. 线性因子模型 / 打分卡
`Score = Σ wᵢzᵢ`，13 个特征固定权重。

### 19. IC（信息系数）/ Rank IC（Spearman）★
- **定义**：因子值与未来收益的相关系数；Rank IC 用秩，抗异常值。
- **代码**：`daily.signal_health`（rank 后滚动 pearson = 滚动 Spearman）。
- **你的数字**：2025+ IC(T+20) +0.30~+0.34；2020-2024 ≈ 0。
- **经验刻度**：单因子 |IC| 0.03~0.05 就可交易；0.1 很强；组合分数 0.3 已偏高（注意样本小）。

### 20. 信号衰减 / 持有期选择（IC decay）
- 你的分数：T+1 IC +0.14、T+5 +0.24、T+20 +0.25（2025+）→ **20 日尺度的信号**，不该做次日择时。

### 21. 因子符号约束（经济逻辑定号）
- `TREND_SIGNS = {sox:+1, turnover:+1, us10y:-1, realized_vol:-1, pe_kc50:-1}`。不拟合符号能大幅降低过拟合。

### 22. 权重裁剪与阈值过滤
- `fit_weights(..., thresh=0.10, cap=0.20)`。

### 23. 样本内 / 样本外 / 数据窥探
- 你的做法：2026-03+ 当优化窗口，看 2025+/2026 是否同向。**反复在同一窗口试错 = 多重检验**，会选到"运气好的参数"。

### 24. 定权 vs 拟合
- 现在是"经济逻辑定号 + 固定权重"，属低自由度设计，是对抗过拟合的正确方向。

## 第四层 · 回测

### 25. 事件驱动 vs 向量化回测
- 你用的是**逐日循环的事件驱动账本**（`simulate_v8` / `simulate_t1`），才能做 T+1 锁仓与盘中动作。

### 26. T+1 制度与仓位账本 ★
- `available`（可卖）/ `locked`（今日买入，次日解锁）。A 股 T+1 是硬约束，忽略它必高估收益。

### 27. 交易成本
- `fee=5e-4`（单边 5bp）。换手 59 次 × 2 × 5bp ≈ 吃掉 6% 收益。**你没有做成本敏感性分析**。

### 28. 成交价假设
- 开盘调仓按 `open`，盘中按触发价。**没有滑点模型、没有成交量约束**。

### 29. 基准与相对收益
- `rel = 标的收益 − 基准收益`，基准默认沪深300。

### 30. 回测偏差清单
前视 / 幸存者 / 样本内 / 成本 / 流动性 / 复权 / 退市 / 时区。

## 第五层 · 仓位与风控

### 31. 分数→仓位映射（分档）★
`base_score_v8`：≥-10→center；-10~-30→0.75c；-30~-60→0.45c；≤-60→floor(3%)。

### 32. 非对称平滑（一阶低通 / EWMA）★
- `tgt_sm = (1-ρ)·pos + ρ·tgt`，**ρ_up=0.8（加仓快）、ρ_down=0.3（减仓慢）**。
- 等价于指数加权移动平均（EWMA）。含义：让盈利奔跑、亏损慢慢处理。

### 33. 步幅限制（rebalancing speed limit）
- `min(order, add_max/10)`。避免单日全仓换手放大成本与择时误差。

### 34. 最小交易阈值
- `min_trade=0.05`，过滤无效小额调仓。

### 35. 仓位上下限（clamp）
- `clip(tgt, 0, 0.90)`。留现金 = 保留期权价值与追加能力。

### 36. 波动率目标（Vol Targeting）★缺失
- 标准做法 `w = σ_target/σ_realized`。你只在**特征层**用了 realized_vol（且权重为 0），**仓位层没有 vol targeting** —— 明显改进空间。

### 37. 趋势跟踪 + 过热修正
- `TrendScore`、`heat_adj`（涨越多，减仓系数越小）。

### 38. 盘中规则
- waterfall 两档瀑布；`rally_plan` / `dip_plan` 随分数分档（越冷冲高越要减、越冷不接飞刀）。

### 39. 紧急风控
- `emerg_sell=(0.035, 3.0)`：日内跌 3.5% 立即减 3 成。

### 40. Regime（状态识别）
- `barometer/regime/engine.py`：用分项分数按**显式规则**分类（不是聚类/隐马）。

## 第六层 · 组合与对冲

### 41. 相关系数 / 滚动相关
`rolling(60).corr()`。

### 42. 相关性门控（correlation gate）★
`corr < -0.05` 才启用银行对冲腿 —— 只有"真能在下跌时反向"的资产才配当对冲。

### 43. 对冲 / 配对
`wk` 科创50腿 = 模型仓位；`wh = 1 - wk` 银行腿。

### 44. 分散化 vs 对冲
- 今天算的：黄金股 vs 科创50 日相关 **+0.31**（正相关）→ 只能分散，不能对冲。

### 45. 组合优化 / 风险预算 ★缺失
- 目前是"两腿 1-w"手工配比，没有协方差矩阵优化、没有风险平价。

## 第七层 · 绩效评估

### 46. 累计收益 / 年化收益（CAGR）
`ann = (1+total)^(244/n) - 1`。

### 47. 最大回撤 MDD
`min(eq/cummax(eq) - 1)`。路径依赖风险，比波动率更贴近真实痛感。

### 48. Calmar 比率
`年化收益 / |MDD|`。你主要用它做参数选择。

### 49. 波动率 / 夏普比率 ★缺失
夏普 =(年化收益 − 无风险利率)/年化波动。**代码里搜不到 sharpe** —— 建议补上，否则"高收益"可能只是高杠杆式的波动。

### 50. 胜率 / 盈亏比 / 期望
`E = p·avg_win − (1-p)·avg_loss`。趋势跟踪型策略通常是"低胜率 + 高盈亏比"。

### 51. 换手率 / 操作日占比
`Σ|Δpos|`。

### 52. 分窗口稳健性
2025+ / 2026 / 2026-03+ / 8月以来 分别验证。

## 第八层 · 统计推断（你最近在用的）

### 53. 事件研究（Event Study）★
- `score_extreme_forwards.py`：定义事件（Score≤-80）→ **合并连续事件** → 算 T+0..T+20 条件前向收益。

### 54. 条件分布 / 条件期望
- 所有"预测"本质是 `E[r | state]`，不是因果。

### 55. 样本量与统计功效
- n=12 时"83% 下跌"的 95% CI 是 **[55%, 95%]** —— 下界很宽。

### 56. 二项置信区间（Wilson）
- `score_extreme_ci.py`。

### 57. 中位数 vs 均值
- 价差均值 +4.73% 但中位 +2.28% → 均值被极端值拉高。

### 58. 稳健性检验（去极值）
- 剔除最好/最差 2 个事件后结论不变，才算稳。

### 59. 重叠样本问题
- 连续 T+5 窗口高度重叠 → **有效样本数远小于名义样本数**，CI 会比算出来的更宽。

### 60. 多重检验 ★缺失
- 你扫了 12 种缩量方案、多组权重、多组调仓参数 → 需要 Bonferroni / White's Reality Check / Deflated Sharpe。
